The Director's Cut

Where the direction is.

Every project on this site says directed by a human, built by AI. This page is where that is shown rather than said. For each project: the brief as it was recorded, the turns where a person changed what the agents had made, the check that decided it was done, and what it does not prove.

Every quotation is a commit message from this repository, unedited. The hashes open the commits on GitHub; the session links open the Claude Code transcripts the commits were made in. Where a project's brief was never written into a commit, that is said instead of paraphrased.

OneSheet

25 Jul → 7 Sep 2026 · open the project →

3 commits touch this directory · 2 linked sessions · human-written code: none claimed

The brief, as recorded

A working spreadsheet with a real formula engine and real .xlsx import, delivered as a single offline HTML file: Pratt-parsed formulas, an incremental dependency graph, a virtualised grid over 5000x702 cells, and a command log that powers undo, redo and a time-travel scrubber from one data structure.
— commit 954e12a, 2026-07-25 · session

The turns

  1. Constraint
    Planned by Claude Fable 5, built by Claude Opus 5, zero human code.

    25 Jul · 954e12a · session

  2. Constraint
    Nothing else on the site is touched — it is one directory with one file in it, no shared assets, no build step.

    25 Jul · 954e12a · session

  3. Send-back
    toolbar scrolls sideways on phones (7 controls were unreachable), API key kept in sessionStorage for the tab instead of localStorage on the shared github.io origin (legacy key migrated and wiped), =AI() model id updated to claude-haiku-4-5-20251001

    7 Sep · eb4d111 · session

The gate

The ⚙ Gate button on the sheet's toolbar runs forty formula checks against the live engine in your own browser and shows the result row by row. Thirty-nine pass. The fortieth is a real engine bug found while writing the table — =SUM over a range that contains text returns #VALUE! where a spreadsheet should ignore the text — and it is marked as known to fail rather than hidden.

What it doesn't prove

  • Fifty-six functions is not Excel. Anything outside that table is unsupported, not approximated.
  • The =AI() real mode has never been exercised against the live API from this repository; only the deterministic mock has.
  • The grid has no ARIA semantics and a document-level Tab hijack (this week's audit, still open).
